Configurable Win–Build–Send Activities

Admin console preview · every activity, achievement trigger, follow-up, and knob is data-configured at runtime — no deploy. Now with full CRUD on every surface. Rendered from the default seeded catalog (WbsActivityCatalogSeeder).

How to read this: the earning surface is organised as phase → category → activity. Each row shows its per-record actions — View Edit Disable — which map to the real REST endpoints below. Editing an activity supersedes its version so the immutable ledger always references the exact rule that paid out; "Disable" is a soft-delete (status = inactive).

PATCH Edited again

Soft-cancel; earned points are not clawed back. Further edits refused.
